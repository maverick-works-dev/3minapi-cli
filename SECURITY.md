# Security policy

## Supported versions

Only the latest published minor version of `3minapi` receives security fixes. Update with:

```sh
npm i -g @3minapi/cli@latest
```

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).

Do not open a public issue for a security problem, and do not include real host tokens
(`tm_host_…`) or other secrets in a report.

We aim to acknowledge reports within 3 business days.

## Scope

This repository is a read-only mirror of the CLI source. Reports about the 3Min API service
itself (`api.3minapi.com`, the dashboard, the MCP server) are also welcome through the same channel.
